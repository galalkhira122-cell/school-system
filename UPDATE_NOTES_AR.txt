تحديث المشروع الأصلي بتاريخ 2026-09-22

الملفات المستبدلة فقط:
- src/api.js: النسخة الحالية المرسلة من المستخدم، تحتفظ برابط Apps Script الحالي.
- src/pages/Attendance.js: نسخة آخر إصلاح ناجح، تحميل سريع مع مسار احتياطي وحفظ مجمع والتحقق من الحفظ.

لم يتم تغيير بقية صفحات المشروع أو package.json أو package-lock.json.
كود Google Apps Script لا يوضع في مشروع React؛ احتفظ بالإصدار المنشور الحالي الذي يعمل.

التشغيل محليا:
npm ci
npm run build

للنشر على Vercel: ارفع هذا المشروع إلى مستودع Git المرتبط بـ Vercel أو انشره بالطريقة الحالية. إعداد Create React App: Build Command = npm run build و Output Directory = build.
تحقق من عمل تحميل الطلاب وحفظ فصل تجريبي بعد النشر. لا تنشر ملف .env الذي يحتوي أسرارا.
